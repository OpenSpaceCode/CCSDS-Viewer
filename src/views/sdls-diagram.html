WHAT IS AUTHENTICATED · WHAT IS ENCRYPTED

Section 5 of the Blue Book lists the four Space Data Link protocols SDLS can secure. For each of them the MAC is computed over a different span of the original frame than the one encryption is applied to: authentication covers the headers and the data, encryption covers the data field alone. The ApplySecurity Payload handed to the sending function runs from the first octet of the Primary Header to the last octet of the Frame Data Field, with the Security Header still empty (§ 3.2.2). The MAC is computed after the SA’s authentication bit mask has been bitwise-ANDed over that span, so any field the mask clears — the Insert Zone, and any volatile field a mission chooses to exclude — contributes zeros instead of its value. At the receiving end the ProcessSecurity Payload additionally carries the Security Trailer, which holds the MAC being verified (§ 3.3.2).
