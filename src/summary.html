CCSDS Protocol Viewer

A quick reference for engineers working on a layered space link: the key information of the CCSDS protocols in one place, instead of a stack of open PDFs. Frame diagrams, a frame builder and a frame decoder, written from the CCSDS Blue Books.

The interactive viewer needs JavaScript. Turn it on and reload this page to use it. Everything runs in your browser: nothing you enter is uploaded.

Protocols

  • Space Packet Protocol (CCSDS 133.0-B-2)
  • TM Space Data Link Protocol (CCSDS 132.0-B-3)
  • TC Space Data Link Protocol (CCSDS 232.0-B-4)
  • Space Data Link Security Protocol, SDLS (CCSDS 355.0-B-2)
  • SDLS Extended Procedures (CCSDS 355.1-B-1)

Features

  • Frame diagrams and a reference page for each field, with links to the Blue Book clause it comes from
  • Frame Builder: fill in the fields of a Space Packet or TM or TC Transfer Frame and get its bits and hex, with lengths and the Frame Error Control Field computed
  • Frame Decoder: paste raw hex to read every field, with consistency checks against the Blue Book, including the CRC
  • SDLS as an option of TM and TC frames: Security Header and Trailer layout, and what each service covers
  • Mission profiles: define managed parameters once, and export or import them as JSON
  • Search across all fields, abbreviations and special values such as 0x7FE
  • A printable one-page cheat sheet per protocol
